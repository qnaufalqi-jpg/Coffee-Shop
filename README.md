# CafeCoffe ☕

CafeCoffe is a modern Android coffee ordering application built with **Jetpack Compose** and **Material 3**. It provides a sleek, user-friendly interface for browsing coffee varieties, managing cart orders, saving favorites, and checking notifications.

---

## ✨ Features

- **Home & Catalog**: Browse coffee items across various categories (*All Coffee*, *Macchiato*, *Latte*, *Americano*, *Expresso*) with real-time search functionality.
- **Coffee Details**: View detailed information, ratings, pricing, and customize your coffee cup size (*S*, *M*, *L*).
- **Shopping Cart**: Add items to cart, adjust quantities, calculate subtotal and delivery fees, and complete your order with a seamless checkout flow.
- **Favorites System**: Bookmark your favorite coffee items and access them instantly in the dedicated **Favorites** screen.
- **Notifications**: Stay updated with order delivery status and special promotional offers.
- **Bottom Navigation**: Easily switch between **Home**, **Favorites**, **Cart**, and **Notifications** using a unified bottom navigation bar.

---

## 📱 Tech Stack

- **Language**: [Kotlin](https://kotlinlang.org/)
- **UI Framework**: [Jetpack Compose](https://developer.android.com/jetpack/compose) (Declarative UI)
- **Design System**: [Material 3](https://m3.material.io/)
- **Architecture**: State-driven UI with Compose State & remember

---

## 🚀 Getting Started

1. Clone the repository or open the project in **Android Studio**.
2. Sync the project with Gradle files.
3. Run the app on an Android emulator or a physical Android device.
